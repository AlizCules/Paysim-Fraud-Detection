# Legacy artifacts

This directory preserves the original notebooks, models, report, and generated outputs for auditability. They are not the canonical recruiter-facing workflow because they contain stale local paths, notebook error output, inconsistent data documentation, or unverifiable evaluation provenance.

Use the reproducible workflow under `src/`, `scripts/`, `results/`, and `docs/` instead.

The current tree intentionally excludes row-level PaySim data. Earlier private history contained a working sample; this branch does not rewrite or erase that history.
