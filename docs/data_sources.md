# Data source, license review, and provenance

Checked: **2026-08-14**.

## Sources checked

1. **Original PaySim project:** [EdgarLopezPhD/PaySim](https://github.com/EdgarLopezPhD/PaySim). Its repository displays a `GPL-3.0` license for the simulator code and points readers to the Kaggle dataset sample. The code license is not treated as a license for the CSV dataset.
2. **Original publication reference:** E. A. Lopez-Rojas, A. Elmir, and S. Axelsson, “PaySim: A financial mobile money simulator for fraud detection,” EMSS 2016. The original project README provides the citation context.
3. **Dataset source:** [Kaggle Synthetic Financial Datasets For Fraud Detection](https://www.kaggle.com/datasets/ealaxi/paysim1). The dataset page currently displays `CC BY-SA 4.0` in its License section and describes the file as synthetic data generated by PaySim.

## Usage versus redistribution

- **Use for analysis:** the dataset is publicly accessible through Kaggle and is suitable for this analysis after the user obtains a permitted copy under the source terms.
- **Redistribution of row-level data:** treated as **UNVERIFIED for this repository**. The Kaggle page displays CC BY-SA 4.0, but this audit did not obtain a separate written authorization from the original simulator authors or verify that the Kaggle uploader's metadata alone resolves all downstream redistribution questions. Public availability is not treated as blanket permission to mirror the CSV.
- **Decision:** do not distribute the raw CSV, the former row-level working sample, or transaction-level prediction exports. Keep only code, documentation, figures, model artifacts, and aggregate result tables.

## Local data contract

The canonical raw filename is `PS_20174392719_1491204439457_log.csv`. The user must obtain a permitted copy from the documented source and place it under `data/raw/`. The repository does not silently fall back to a sample; missing data raises an explicit message.

The local source previously used for the canonical run contained 6,362,620 rows, 11 columns, steps 1-743, and 8,213 fraud rows. Those counts remain documented in aggregate artifacts, but row-level PaySim data is not in the current Git tree.

## Historical exposure note

Earlier private history contained a working sample. The public branch/current tree excludes row-level PaySim data. This cleanup does not erase or rewrite historical commits, and the repository has not been represented as having erased history.

PaySim is a simulation. Findings describe patterns within the simulated environment and should not be read as claims about real bank customers, real fraud losses, or production fraud operations.
