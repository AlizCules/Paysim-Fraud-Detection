# Local PaySim data location

No row-level PaySim data is distributed in this repository.

To run the canonical pipeline, obtain a permitted copy from the documented source and place the file here:

```text
data/raw/PS_20174392719_1491204439457_log.csv
```

The CSV name and directory are ignored by Git. Do not commit the raw file or a row-level subset. See [`docs/data_sources.md`](../../docs/data_sources.md) before sharing or redistributing any copy.
